# Assignment Template Generator

A static, browser-based assignment generator with two selectable cover-page designs:
- Layout 1: Classic university cover
- Layout 2: Faculty / PSTU-style cover based on the supplied PDF

Visitors can edit student/course/submission details and both assignment answers, preview the document, and use Print → Save as PDF. The second layout includes the university logo extracted from the supplied reference PDF. No visitor data is uploaded or stored.

## Run locally
Open `index.html` in a modern browser. Keep `index.html` self-contained; the logo is embedded in it.

## Publish a public link with GitHub Pages
1. Create a **public** repository on GitHub.
2. Upload `index.html` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will publish a public URL similar to `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
